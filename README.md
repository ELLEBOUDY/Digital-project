# DigitalPro — Marketing Agency Landing Page

A modern, responsive landing page for a digital marketing agency. Built with Tailwind CSS (CDN) and Font Awesome, featuring a hero section, services, stats, team showcase, and contact form.

## Overview
DigitalPro is a single-page marketing website designed for agencies and service-based businesses. The layout emphasizes clear hierarchy, strong CTAs, and modern visual styling.

## Features
- Fixed navigation with CTA and account actions
- Hero section with stats and highlights
- Services grid with interactive hover states
- KPI band for quick credibility metrics
- Team section with social hover overlays
- Contact form and company information footer

## Tech Stack
- HTML5
- Tailwind CSS (CDN)
- Font Awesome (CDN)

## Project Structure
- `index.html` Main page markup
- `css/style.css` Minimal base styles (reset only)
- `javaScript/script.js` Reserved for interactive behavior
- `images/` Static assets
- `webfonts/` Font Awesome webfonts
- `tailwind.config.js` Tailwind configuration (CDN usage)

## Getting Started
1. Open `index.html` directly in a browser, or use a local server.
2. Optional: Use the VS Code Live Server extension for hot reload.

## Customization
- Brand colors and typography: adjust Tailwind utility classes in `index.html`.
- Tailwind config: edit `tailwind.config.js` to extend theme values.
- Icons: replace Font Awesome classes in `index.html`.
- Content: update sections and copy directly in `index.html`.

## Notes
- The project uses Tailwind via CDN, so no build step is required.
- `javaScript/script.js` is currently empty and ready for enhancements (menu, animations, form handling).
